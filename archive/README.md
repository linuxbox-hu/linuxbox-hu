# Archive

Superseded config files from setting up the Hugo migration test, kept for reference
rather than deleted. None of these are read by the live build — only `config.toml`
(repo root) is active.

- `config-base.toml` / `config-base-2.toml` — earlier draft configs from before
  `config.toml` was built out (theme defaults, alternate `baseURL`).
- `config-minimal.yaml` — a bare-bones config used for an early smoke test,
  pointed at the GitHub Pages URL rather than `hugo.linuxbox.hu`.
